# StudyFlow Web (scaffold)

Versão web inicial do StudyFlow usando React + Vite + MUI + Tailwind + Firebase.

## Setup rápido

1. Instalar dependências:

```bash
cd web
npm install
```

2. Crie `.env` a partir de `.env.example` e preencha as credenciais do Firebase.

3. Rodar em desenvolvimento:

```bash
npm run dev
```

## Estrutura

- `src/` - código fonte React
- `src/firebase.ts` - inicialização do Firebase
- `src/components/` - componentes principais (AppBar, BottomNav, TaskCard)
- `index.html` - ponto de entrada
